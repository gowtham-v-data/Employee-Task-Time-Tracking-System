# 🚀 VS Code Extension - Quick Start

## ⚡ 3 Steps to Get Started

### Step 1: Run Setup Script
```bash
cd vscode-extension
.\setup-and-compile.bat
```

### Step 2: Press F5 in VS Code
Opens a test window with the extension loaded

- Password: `Employee@123`
